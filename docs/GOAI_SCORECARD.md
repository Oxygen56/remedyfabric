# GOAI Agent Infra Score Mapping

| Official dimension | Weight | RemedyFabric evidence | Remaining proof before freeze |
| --- | ---: | --- | --- |
| Scenario value and replicability | 25% | Repository failure recovery is a cross-team infrastructure problem; zero-credential demo and provider-neutral contract | Add one external repository incident and independent clone/run evidence |
| Multi-Agent collaboration and autonomous loop | 25% | Four distinct Workers plus Manager; typed state transitions; commit/block/rollback terminal outcomes | Run the declarative team on official AgentTeams and capture Matrix/Controller trace |
| Skill engineering and reuse | 25% | Versioned `remedyfabric-recovery` Skill, typed input/output, preconditions, policy, failure and replacement contract | Package and assign Skill to AgentTeams Workers; optionally install one official Alibaba Cloud Skill |
| Engineering, verification, safety and audit | 20% | Bounded executor, protected paths, old-content preconditions, independent invariants, byte-exact rollback, hash-chain ledger, tests, benchmark and ablations | Add container network isolation, signed release and public CI proof |
| Open/open-source contribution | 5% | Apache-2.0 source, docs, fixtures, benchmark, dashboard and deployment manifests | Public repository, tagged release, contribution guide and issue templates |

## Claim boundary

The score mapping shows artifact coverage, not a predicted judge score. Local tests do not prove production reliability; AgentTeams configuration does not prove a live deployment until a captured run exists.
