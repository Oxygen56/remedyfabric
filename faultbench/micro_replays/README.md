# Independent semantic micro-replays

These three fixtures were independently written from the public diffs linked in each
`provenance.json`. They demonstrate one before/after semantic from one Python, one JavaScript,
and one Rust fix. They are deliberately small enough to run without downloading upstream
dependencies.

They are **not** checkouts of the pre-fix repositories, upstream regression tests, complete patch
replays, or evidence that RemedyFabric generated any of the fixes. The raw GitHub verification
receipt preserves the official merge-commit payload, including public file patches exposed by the
API, so a reviewer can audit the semantic mapping.
